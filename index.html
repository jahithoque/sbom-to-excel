How do I get SBOMs for the images in my cluster?

List the images running in the cluster

kubectl get pods -A -o jsonpath='{range .items[*].spec.containers[*]}{.image}{"\n"}{end}' | sort -u > images.txt

Generate one SBOM per image with Syft or Trivy

while read -r img; do
  syft "$img" -o cyclonedx-json > "sbom-$(echo "$img" | tr '/:@' '___').json"
done < images.txt

# or
trivy image --format cyclonedx --output sbom.json IMAGE

Images in Artifact Registry can export SPDX SBOMs from Artifact Analysis:

gcloud artifacts sbom export --uri=REGION-docker.pkg.dev/PROJECT/REPO/IMAGE@sha256:DIGEST

Then drop all the resulting .json files (or the folder) above.
